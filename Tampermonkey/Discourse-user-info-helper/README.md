# Discourse 论坛用户注册信息辅助

逛 `linux.do`、`idcflare.com` 等 Discourse 论坛看帖子时，在用户名旁直接显示注册天数、发帖数、回帖数和信任级别，一眼看清发帖人资历，同时按需加载、不刷爆论坛接口。

## 核心功能

1. **楼主信息自动显示**
   - 打开帖子后，自动在 1 楼作者用户名旁追加一行信息，例如：`· 注册 365 天 · 发帖 12 · 回帖 230 · Lv3 常驻`。
   - 同一用户在同一页内只查一次并本地缓存，翻回时不会重复请求。

2. **楼下回帖按需点查**
   - 为避免一口气向论坛发太多请求触发限流，楼下回帖旁默认只放一个轻量「**查看用户信息**」按钮，想查谁就点谁。
   - 若遇到网络波动或临时限流，按钮会变为「**重试**」，随时可再点一次。

3. **右侧悬浮条一键批量查看**
   - 帖子页右下角常驻一个毛玻璃悬浮条，点击「**展示已加载用户信息**」即可依次查完当前屏幕附近已渲染的所有回帖用户（请求之间自动间隔节流）。
   - 可随时点击「**隐藏 / 展开**」把悬浮条收在屏幕边缘，也可以按住上下拖动到顺手的位置，刷新页面后仍会记住。

## 默认支持与扩展其他论坛

- **默认开箱支持**：`https://linux.do/*` 与 `https://idcflare.com/*`。
- **支持任意 Discourse 论坛**：接口地址按当前访问站点动态拼装，无任何写死域名。如果想用在其他同类型论坛，只需在油猴管理面板里打开本脚本的「设置 → 用户匹配」，添加该论坛地址（例如 `https://your-forum.example/*`）即可生效，无需修改代码。

## 安装与使用

1. **安装脚本管理器**：先在浏览器安装 Tampermonkey（油猴）等用户脚本管理器。
2. **一键安装**：[点击安装 Discourse 论坛用户注册信息辅助](https://raw.githubusercontent.com/iamvicliu/Script/main/Tampermonkey/Discourse-user-info-helper/Discourse-user-info-helper.user.js)。
3. **直接逛帖即可生效**：无需额外配置，进入任意帖子页即可看到效果；浅色和深色主题自动适配。
