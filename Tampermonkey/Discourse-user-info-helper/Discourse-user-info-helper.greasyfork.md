# Discourse 论坛用户注册信息辅助

逛 `linux.do`、`idcflare.com` 等 Discourse 论坛看帖子时，在用户名旁直接显示注册天数、发帖数、回帖数和信任级别，一眼看清发帖人资历，同时按需加载、不刷爆论坛接口。

## 核心功能

1. **楼主信息自动显示**
   - 打开帖子后，自动在 1 楼作者用户名旁追加信息，例如：`· 注册 365 天 · 发帖 12 · 回帖 230 · Lv3 常驻`，同一用户会复用本地缓存，不重复发请求。

2. **楼下回帖按需点查**
   - 楼下回帖旁默认只放「**查看用户信息**」按钮，想查谁点谁，避免一次发过多请求触发论坛限流；加载失败时支持点击「**重试**」。

3. **右侧悬浮条一键批量查看**
   - 点击右下角「**展示已加载用户信息**」，可依次加载当前页已渲染的所有回复用户（自动间隔节流）。
   - 支持点击「**隐藏 / 展开**」收边，也支持上下拖动调整位置并记忆高度，浅色与深色主题自动适配。

## 默认支持与自定义扩展

- 默认支持：`https://linux.do/*`、`https://idcflare.com/*`。
- 如需用于其他 Discourse 论坛，直接在油猴脚本「设置 → 用户匹配」里加入对应网址即可自动生效，无需修改源码。

> **实测情况**：已在 linux.do / idcflare.com 真实网页实测通过；如遇论坛页面改版导致异常，欢迎反馈。

## 安装与隐私说明

- 安装前提：先在浏览器安装 Tampermonkey（油猴）等用户脚本管理器。
- GitHub 直装地址：
  `https://raw.githubusercontent.com/iamvicliu/Script/main/Tampermonkey/Discourse-user-info-helper/Discourse-user-info-helper.user.js`
- 仅在浏览器本地调用当前论坛自带的用户公开接口（随当前登录态读取），不向任何第三方发送或收集个人数据；MIT 协议开源，与上述论坛及 Discourse 官方无关联。
