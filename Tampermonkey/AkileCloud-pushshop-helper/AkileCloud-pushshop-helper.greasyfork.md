# AkileCloud Push 市场助手

在 AkileCloud Push 交易市场（`/console/pushshop`）中，一键把服务器卡片整理为可排序的溢价与预算测算表格，并将刷新按钮移动到搜索框旁；两项功能可在油猴菜单单独开关。

## 核心功能

1. **一键生成溢价计算表格**
   - 点击右上角「**生成表格视图**」，把当前页面服务器卡片整理为表格（含配置、带宽、流量、IPv4/IPv6、续费价格、到期时间、售价、溢价金额、预算可用至及可折叠的官方描述）。
   - 支持点击表头按真实数值与单位排序（自动换算 `Gbps/Mbps`、`TB/GB/MB`，月付/季付/半年付/年付分组排序，空值自动沉底）。
   - 表格页内可实时修改「**预算金额（元）**」重算可用日期，并支持「**复制当前表格**」直接粘贴到 Excel / 表格软件；若浏览器拦截新标签页会自动在页内浮层展示。

2. **移动刷新按钮到搜索框旁**
   - 将原刷新按钮顺手放到搜索框末尾（点击仍触发页面原有刷新逻辑），关闭开关或离开市场页面时自动恢复原位，不破坏页面交互。

3. **计算口径说明**
   - **溢价金额** = 售价 − 剩余价值（剩余天数 × 日均续费成本）；绿色为无溢价/折价，红色为溢价。
   - **预算可用至** = 在机器现有到期日的基础上，加上 `(预算 − 售价) ÷ 日均续费成本` 对应天数；若预算低于售价则提示差额。

> **实测情况**：已完成本地仿真与自动化校验，待真实 AkileCloud Push 市场页面实测确认；如遇页面改版导致字段匹配异常，欢迎反馈。
