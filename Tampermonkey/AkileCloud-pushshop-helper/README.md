# AkileCloud Push 市场助手

在 AkileCloud Push 交易市场页面一键把零散的服务器卡片整理成可排序的溢价计算表格，并把页面原本的刷新按钮顺手移到搜索框旁边；两项功能互不干扰，均可在油猴菜单中单独开关。

## 核心功能

1. **服务器列表一键转表格 & 溢价/预算测算**
   - 在 Push 市场页面右上角提供「**生成表格视图**」按钮，将当前页面的全部服务器卡片整理为结构化表格。
   - **字段一览**：套餐名称、IP 状态、官方描述（默认隐藏，可一键显示/隐藏）、配置、带宽、已用流量、总流量、IPv4、IPv6、续费价格、重置流量、到期时间、售价、溢价金额、以及「X 元可用至」。
   - **按真实数值与单位排序**：点击任意表头即可升降序排列——带宽自动换算（`Gbps` / `Mbps`）、流量自动换算（`TB` / `GB` / `MB`）、续费价格按周期与金额排、缺失数据自动沉底。
   - **表格页直接调预算与复制**：新打开的表格页面自带「**预算金额（元）**」输入框（修改后实时重算能用到哪一天）以及「**复制当前表格**」按钮（一键复制制表符表格，可直接粘贴进 Excel、Numbers 或飞书表格）。
   - **弹窗被拦截也不怕**：如果浏览器拦截了新标签页弹窗，会在当前页面内自动弹出表格浮层兜底查看。

2. **刷新按钮移至搜索框旁（非破坏式还原）**
   - 自动在搜索框右侧紧挨着放一个顺手的刷新按钮，点它与点原刷新按钮效果完全一致。
   - 不删除页面原有组件，随时可在油猴菜单关闭该功能或切离市场页面时完整恢复原状。

## 计算口径说明

- **剩余价值与溢价金额**：先按续费价格与周期（月 / 季 / 半年 / 年）折算出每日费用，再用「到期时间距今的剩余天数 × 每日费用」估算当前剩余价值；**溢价金额 = 当前售价 − 剩余价值**（绿色表示折价或平价，红色表示存在溢价）。
- **预算可用至**：当总预算大于等于当前售价时，在机器**已有到期日**基础上，加上 `(预算 − 售价) ÷ 每日续费成本` 可续费的天数，推算出该预算累计可用到的日期；若预算低于当前售价，则直接提示「预算不足（差 ￥X）」。

## 油猴菜单设置

安装后点击浏览器右上角 Tampermonkey（油猴）图标，即可看到本脚本菜单：

- **表格视图与溢价计算**：单独开启 / 关闭右上角「生成表格视图」按钮（默认开启）。
- **刷新按钮移至搜索框旁**：单独开启 / 关闭搜索框旁刷新按钮移动（默认开启）。
- **设置默认预算（当前 200 元）**：自定义打开表格时默认填入的总预算金额。

## 安装与使用

1. **安装脚本管理器**：先在浏览器安装 Tampermonkey（油猴）等用户脚本管理器。
2. **一键安装**：[点击安装 AkileCloud Push 市场助手](https://raw.githubusercontent.com/iamvicliu/Script/main/Tampermonkey/AkileCloud-pushshop-helper/AkileCloud-pushshop-helper.user.js)。
3. **打开 Push 市场**：访问 `https://akile.io/console/pushshop`，等待服务器列表加载后即可看到搜索框旁的刷新按钮与右上角「生成表格视图」按钮；离开该页面后脚本自动休眠。
