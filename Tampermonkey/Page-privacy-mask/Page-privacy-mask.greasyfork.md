# 网页隐私打码助手 (IP / 邮箱 / 手机 / 选中打码)

截图、录屏或演示网页前，自动给页面里的 IP（IPv4 / IPv6）、邮箱和手机号打码，避免误露隐私；支持点小眼睛查看原文、手动选中任意文字打码、按站点暂停与复制局部脱敏。

## 核心功能

1. **自动识别打码（IP / 邮箱 / 手机号）**
   - 默认自动打码 IPv4 与 IPv6（严格校验格式，不误伤 `std::vector`、`::before`、时间 `12:34:56`、版本号与时间戳/订单号）。
   - 设置弹窗可按需开启邮箱与手机号打码；自动跳过输入框与代码编辑器，不影响正常打字。

2. **点小眼睛随时查看 / 还原原文**
   - 每处打码旁都有绿色小眼睛按钮，点一下切换显示原文或重新打码；油猴菜单也可一键还原整页打码。

3. **手动选中文字打码（`Alt + Shift + M`）**
   - 选中页面任意敏感文字后按 `Alt + Shift + M` 或从油猴菜单触发，即可手动遮住并同样支持点小眼睛还原。

4. **按当前网站暂停 & 复制局部脱敏**
   - 油猴菜单支持对当前网站一键暂停/恢复；设置开启「复制文本时仅将敏感词替换为星号」后，复制整段内容时只脱敏其中的敏感词，保留前后正常文字。

> **实测情况**：核心功能已在真实 Chrome 网页实测通过；如遇个别复杂网页兼容问题，欢迎反馈。
