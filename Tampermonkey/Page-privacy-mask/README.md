# 网页隐私打码助手 (IP / 邮箱 / 手机 / 选中打码)

截图、录屏或远程演示前，自动给网页上的 IP（IPv4 / IPv6）、邮箱和手机号打码，避免不小心泄露隐私信息；平时浏览随时按站点暂停，想看原文点一下小眼睛即可。

## 核心功能

1. **自动识别并给敏感信息打码**
   - 默认自动打码 **IPv4 与 IPv6 地址**，精准校验格式，不会把代码里的 `std::vector`、`::before`、`12:34:56` 时间戳、软件版本号或长数字订单号误当成 IP。
   - 可在设置里按需勾选 **邮箱** 与 **手机号**，自动跳过输入框、评论框和在线代码编辑器，不破坏正常输入。

2. **随时点小眼睛查看或恢复原文**
   - 每处打码旁边都带有一个绿色小眼睛按钮，点击即可临时查看原文，再点一下重新遮住；重复扫描页面也不会长出多个眼睛。
   - 也支持通过油猴菜单一键「**还原当前页全部打码**」。

3. **手动选中任意文字打码**
   - 截图前发现页面上有账单号、密钥或自定义名称想遮挡，用鼠标选中文字后按快捷键 **`Alt + Shift + M`**（或在油猴菜单点「手动打码选中文字」），立刻变成可随时还原的星号遮罩。

4. **按当前网站暂停 & 复制局部脱敏**
   - 油猴菜单支持对当前域名一键「**暂停 / 恢复自动打码**」，不想在常用网站一直开着时很方便。
   - 设置里可选开启「**复制文本时仅将敏感词替换为星号**」，复制整段日志或文字时只替换里面的敏感词，完整保留其余说明文字。

## 安装与使用

1. **安装脚本管理器**：先在浏览器安装 Tampermonkey（油猴）等用户脚本管理器。
2. **一键安装**：[点击安装网页隐私打码助手](https://raw.githubusercontent.com/iamvicliu/Script/main/Tampermonkey/Page-privacy-mask/Page-privacy-mask.user.js)。
3. **打开设置或快捷使用**：点击浏览器右上角油猴图标即可打开设置面板、立即扫描、手动选中打码、全部还原或暂停当前网站；手动选中文字后也可直接按 `Alt + Shift + M`。

## 说明与隐私

- **实测情况**：核心功能已在真实 Chrome 网页实测通过；如遇个别复杂网页兼容问题，欢迎反馈。
- **纯本地处理、不联网**：所有匹配与遮罩均在当前浏览器页面内完成，不读取密码框内容，不向任何外部服务器发送页面文本或配置。
- **开源许可**：个人维护的页面辅助工具，以 MIT 协议开源。
