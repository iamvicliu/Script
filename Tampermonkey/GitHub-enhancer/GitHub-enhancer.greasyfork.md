# GitHub 增强套件 (GitHub Enhancer)

针对 GitHub 的轻量模块化界面与交互增强脚本，聚焦三项高频痛点且保持独立菜单开关。

## 功能

1. **Private / Public / Internal 可见性区分增强**
   - 强化仓库列表页（高亮徽章与左侧强调条）与详情页全子页（顶栏视觉条、锁图标着色、常驻可见性徽章、私有库标签页 `🔒 ` 前缀）的视觉区分。
   - 内置两套配色方案（琥珀金 / 翠绿、警示红 / 灰蓝），自适应 GitHub 浅色与深色主题。

2. **Releases 平台筛选与长更新日志折叠**
   - 仅在 Releases 页面生效，首次自动识别当前系统平台筛选下载资产（始终保留 `Source code` 与常见校验文件），离开页面自动清理状态。
   - 提供顶部隐藏计数提示与「临时显示全部」按钮、右侧悬浮筛选面板，以及超长 Release 说明自动折叠 / 展开。
   - 采用纯类名隐藏方案，兼容第三方高速下载脚本。

3. **禁用易误触单键快捷键（`s` / `w`）**
   - 在非输入区域、非组合键且非输入法合成状态下，拦截全局 `s` 与 `w` 单键快捷键，避免浏览代码或阅读文档时误跳搜索框或切换监控。

> ⚠️ 实测说明：功能 1 已在真实 GitHub 页面验证；功能 2 与功能 3 已通过本地自动化 DOM 回归测试，尚未在真实 Chrome 登录态 Releases 页面做实机点验，如遇 GitHub 改版异常欢迎反馈。

## 安装

- GitHub 直装地址：
  `https://raw.githubusercontent.com/iamvicliu/Script/main/Tampermonkey/GitHub-enhancer/GitHub-enhancer.user.js`

安装前请先装好 Tampermonkey 一类的用户脚本管理器。

## 使用

1. 安装并启用脚本后，打开任意 GitHub 页面即可自动生效。
2. 点击浏览器 Tampermonkey 图标菜单，可逐项开关各功能模块与配色方案，修改后即时生效，无需刷新页面。

## 说明

- 脚本仅调整本地页面显示与键盘事件，不收集、不上传任何账号数据、Cookie 或仓库信息。
- 仅在 `https://github.com/*` 运行；功能 2 仅在 Releases 页面激活，离开页面自动清理状态。
- 这是个人维护的页面辅助脚本，MIT 协议开源，与 GitHub 官方无关联。
