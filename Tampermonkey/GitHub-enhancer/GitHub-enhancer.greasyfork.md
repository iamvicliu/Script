# GitHub 增强套件 (GitHub Enhancer)

一个油猴脚本解决逛 GitHub 最常见的四个顺手问题：**点图不再跳走、下载自动筛对系统、公开和私有仓库一眼分清、看代码不怕误按快捷键**。四项功能互相独立，随时可在油猴菜单里单独开关。

## 核心功能

1. **Markdown 图片点击原地看大图**
   - 点击 README、Issue、PR、Release 正文图片时，直接在当前页面弹出深色大图预览，不再跳去单独的文件页。
   - 支持滚轮或顶栏按钮缩放（`25%–500%`）、放大后按住拖动、双击切换 `1:1` 与适应窗口、键盘 `←` / `→` 翻看当前正文内的其他图片，按 `Esc` 或点空白处关闭；顶栏保留「原图 ↗」与「仓库文件 ↗」直达入口。
   - 不会误拦项目小徽章、头像、小图标和带外链的按钮图片；按住 `Cmd / Ctrl` 点击图片仍可直接在新标签页打开原链接。

2. **Releases 按系统筛选安装包与长日志折叠**
   - 仅在 Releases 页面生效，首次访问自动识别当前系统（Windows / macOS / Linux / Android）筛选对应安装包，同时保留源码包（`Source code`）与不含特定平台名称的通用文件（如通用校验文件）。
   - 文件列表顶部显示隐藏数量并提供「临时显示全部」按钮，右侧提供「平台筛选」悬浮面板，超长更新日志自动折叠并可一键展开。
   - 不改动下载链接结构，可与第三方 GitHub 高速下载脚本同时开启，互不冲突；切到其他页面会自动收起。

3. **公开 / 私有仓库一眼区分（Public / Private / Internal）**
   - 仓库列表高亮显示公开、私有与内部标签，私有仓库左侧加醒目色条；进入仓库任意子页（代码、Issues、PR、Actions、设置等），顶栏保留彩色细条、着色锁图标与常驻状态标签，私有仓库标签页标题最前面自动加上 `🔒 `，开再多标签页也不会看混。
   - 内置两套配色（默认「琥珀金 + 翠绿」：私有琥珀金 / 公开翠绿；备选「警示红 Private」：私有警示红 / 公开柔和灰蓝），自动适配 GitHub 浅色与深色模式。

4. **屏蔽易误触单键快捷键（`s` / `w`）**
   - 浏览代码或读文档时屏蔽单独按 `s` 或 `w` 键，防止误跳搜索框或误开关仓库 Watch 关注通知。
   - 在输入框、评论区、代码编辑器里输入，使用中文输入法选字，或按 `Ctrl / Cmd / Alt` 组合键时完全不受影响。

## 安装与使用

- 安装前提：先在浏览器安装 Tampermonkey（油猴）等用户脚本管理器。
- GitHub 直装地址：
  `https://raw.githubusercontent.com/iamvicliu/Script/main/Tampermonkey/GitHub-enhancer/GitHub-enhancer.user.js`
- 使用方式：安装启用后打开任意 GitHub 页面即可生效；点击浏览器油猴图标，按中文功能名即可单独开关各项功能或切换配色，修改后立刻生效无需刷新。
