# GitHub 增强套件 (GitHub Enhancer)

针对 GitHub 的轻量模块化油猴脚本，把日常浏览仓库时最常遇到的四个高频小痛点整合在一个脚本里，所有功能都可以在浏览器油猴菜单中单独开启或关闭。

## 核心功能

1. **仓库可见性醒目区分（Private / Public / Internal）**
   - 仓库列表页高亮显示可见性徽章，并为私有仓库左侧加上强调边条，一眼区分公开与私有。
   - 仓库详情页全子页（Code / Issues / PR / Releases / Settings 等）显示顶部视觉条、锁图标着色、常驻可见性标签，并在私有仓库浏览器标签页前置 `🔒 ` 提醒。
   - 内置两套配色方案（琥珀金 / 翠绿、警示红 / 灰蓝），自适应 GitHub 浅色与深色主题。

2. **Releases 平台筛选与长更新日志折叠**
   - 仅在 Releases 页面生效，首次访问自动识别当前操作系统筛选对应的安装包（始终保留 `Source code` 与常见校验文件），离开 Releases 页面后自动清理状态。
   - 页面顶部显示被隐藏的资产数量并提供「临时显示全部」按钮，右侧提供快捷筛选面板，超长更新日志自动折叠并可一键展开。
   - 采用纯类名隐藏实现，兼容第三方 GitHub 高速下载脚本。

3. **屏蔽易误触单键快捷键（`s` / `w`）**
   - 在浏览代码或阅读文档时拦截全局单键 `s` 和 `w`，避免误跳搜索框或误切换仓库 Watch 状态。
   - 在输入框、文本域、组合键或中文输入法合成状态下自动放行，不影响正常输入与浏览操作。

4. **Markdown 图片点击原地看大图**
   - 点击 README、Issue、PR、Release 正文中的图片时，在当前页面直接弹出暗色灯箱查看，不再跳转到 GitHub 仓库文件详情页。
   - 支持滚轮缩放（25%–500%）、放大拖拽平移、双击切换适应屏幕 / 原始尺寸、`←` / `→` 切换整页多图画廊，顶部工具栏保留「原图 ↗」与「仓库文件 ↗」直达入口。
   - 自动放行徽章、贡献者头像与外部跳转按钮；按住 `Cmd / Ctrl` 点击图片仍可直接在新标签页打开原链接。

## 安装与使用

1. 安装前提：先在浏览器中安装 Tampermonkey 等用户脚本管理器。
2. 一键安装脚本：
   [点击安装 GitHub 增强套件](https://raw.githubusercontent.com/iamvicliu/Script/main/Tampermonkey/GitHub-enhancer/GitHub-enhancer.user.js)
3. 模块开关与切换配色：点击浏览器右上角的 Tampermonkey 扩展图标，即可在菜单中逐项开关各功能模块和切换配色方案，修改后即时生效，无需刷新页面。

## 实测状态与隐私说明

> ⚠️ 实测说明：功能 1 与功能 4 已在真实 GitHub 页面验证；功能 2 与功能 3 已通过本地自动化回归测试，尚未在真实 Chrome 登录态页面完成全量点验，如遇 GitHub 改版异常欢迎反馈。

- **隐私与运行范围**：仅在 `https://github.com/*` 本地页面调整样式与交互事件，不收集、不上传任何账号信息、Cookie 或仓库数据。
- **开源许可**：个人维护的页面辅助工具，以 MIT 协议开源，与 GitHub 官方无关联。
