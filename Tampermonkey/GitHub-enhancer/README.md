# GitHub 增强套件 (GitHub Enhancer)

一个油猴脚本解决逛 GitHub 最常见的四个顺手问题：**点图不再跳走、下载自动筛对系统、公开和私有仓库一眼分清、看代码不怕误按快捷键**。四项功能互相独立，随时可在油猴菜单里单独开关，不用装一堆零散脚本。

## 功能速览

| 功能 | 解决什么问题 | 生效页面 |
| :--- | :--- | :--- |
| **1. 图片点击原地看大图** | 点正文图片直接弹出大图，不再跳去文件页 | README / Issue / PR / Release |
| **2. Releases 下载筛选与日志折叠** | 自动筛出你当前系统的安装包，折叠过长更新日志 | Releases 页面 |
| **3. 公开 / 私有仓库一眼区分** | 醒目标记公开、私有与内部仓库，防止看混或误分享 | 仓库列表 / 仓库内所有页面 |
| **4. 屏蔽易误触单键快捷键** | 屏蔽单独按 `s` / `w`，防误跳搜索或误改关注状态 | GitHub 全站 |

## 核心功能

### 1. Markdown 图片点击原地看大图

在 README、Issue、PR、Release 正文里点图片时，直接在当前页面弹出深色大图预览，不再像 GitHub 默认那样跳去单独的图片文件页、看完还得点返回。

| 操作 | 效果 |
| :--- | :--- |
| 单击正文图片 | 原地弹出大图预览 |
| 滚轮 / 顶栏 `−` `+` | 缩放图片（支持 `25%–500%`） |
| 放大后按住拖动 | 自由平移查看细节 |
| 双击图片 / 点 `1:1` 或 `适应` | 在原始比例与适应窗口间切换 |
| 键盘 `←` `→` / 两侧箭头 | 翻看当前正文区域内的其他图片 |
| `Esc` / 点空白处 / 点 `✕` | 关闭大图预览 |
| 按住 `Cmd` 或 `Ctrl` 点击图片 | 按原方式直接在新标签页打开原链接 |

- 顶栏提供 **原图 ↗** 和 **仓库文件 ↗** 入口，想看原文件依然一步直达。
- 不会误拦项目小徽章、头像、小图标和带外链的按钮图片，这些链接照常正常跳转。

### 2. Releases 按系统筛选安装包与长日志折叠

打开 Releases 页面时，不再需要在几十个不同系统的安装包里大海捞针：

- **自动筛出匹配系统**：首次访问自动识别当前系统（支持 Windows、macOS、Linux、Android），只显示匹配的安装包，同时始终保留源码包（`Source code`）和不含特定平台名称的通用文件（如通用校验文件 `checksums.txt`）。
- **随时一键切回全部**：文件列表顶部会提示隐藏了多少个其他平台文件，点「**临时显示全部**」即可全部展开；页面右侧还提供「**平台筛选**」悬浮按钮，可随时切换多平台或查看全部。
- **超长更新说明自动收起**：说明过长（超过约 420px）时自动折叠并显示「**展开完整说明** / **收起说明**」，快速直达下方下载区。
- **兼容其他下载脚本**：不改动原有下载链接结构，可与第三方 GitHub 高速下载脚本同时开启，互不冲突；且只在 Releases 页面出现，切到其他页面会自动收起。

### 3. 公开 / 私有仓库一眼区分（Public / Private / Internal）

同时维护公开项目和私人项目时，帮你一眼分清当前仓库是不是私有库，减少误公开或误截图的风险：

- **仓库列表更醒目**：高亮显示公开、私有与内部标签，私有仓库左侧额外加一道醒目色条。
- **进入仓库全程提醒**：无论切到代码、Issues、PR、Actions 还是设置页，页面顶部都保留彩色细条、着色锁图标与常驻状态标签。
- **浏览器标签页防看混**：私有仓库的标签页标题最前面会自动加上 `🔒 `，同时开十几个标签页也不会弄错。
- **两套配色自适应主题**：内置 **琥珀金 + 翠绿**（默认：私有琥珀金 / 公开翠绿）和 **警示红 Private**（备选：私有警示红 / 公开柔和灰蓝），自动适配 GitHub 浅色与深色模式。

### 4. 屏蔽易误触单键快捷键（`s` / `w`）

- 看代码或读文档时，屏蔽单独按下 `s` 或 `w` 键，避免手滑突然跳进顶部搜索框，或误开关仓库的 Watch 关注通知。
- **正常打字完全不受影响**：在搜索框、评论区、代码编辑器里输入，使用中文输入法选字，或按 `Ctrl` / `Cmd` / `Alt` 组合键（如 `Cmd/Ctrl + S`）时都会照常生效。

## 安装与使用

1. **安装脚本管理器**：先在浏览器安装 Tampermonkey（油猴）等用户脚本管理器。
2. **一键安装**：[点击安装 GitHub 增强套件](https://raw.githubusercontent.com/iamvicliu/Script/main/Tampermonkey/GitHub-enhancer/GitHub-enhancer.user.js)。
3. **自由开关与切换配色**：打开任意 GitHub 页面即可生效。点击浏览器右上角的油猴图标，就能按中文功能名单独开关各项功能或切换配色，修改后立刻生效，不用刷新页面（提示：油猴菜单里的开关仍按最初开发顺序排布，直接认准功能名称开关即可）。

## 说明与隐私

- **实测情况**：四项核心功能均已在真实 GitHub 网页实测通过；如遇 GitHub 页面改版导致异常，欢迎反馈。
- **不联网、不收集隐私**：仅在浏览器本地调整页面显示与按键响应，不发送外部请求，不收集或上传任何账号信息、Cookie 或仓库数据。
- **仅在 GitHub 运行**：脚本只作用于 `https://github.com/*`，不影响其他网站。
- **开源许可**：个人维护的页面辅助工具，以 MIT 协议开源，与 GitHub 官方无关联。
