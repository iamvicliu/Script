# 暗黑核-暗黑破坏神4 BD增强

面向暗黑核《暗黑破坏神4》BD 规划器的全屏浏览增强脚本，支持在全屏下直接切换模块与 BD 变体，并保留巅峰面板与雕文信息。

## 核心功能

### 全屏模块切换

- 全屏顶部增加「总览 / 技能 / 巅峰 / 雇佣兵」切换栏，四个模块可在全屏状态下直接切换，无需反复退出。
- 总览和雇佣兵普通页面增加「全屏」入口。
- 全屏顶部支持直接切换当前 BD 的不同变体。
- 支持按 `Esc` 键或点击「退出全屏」返回普通页面。

### 巅峰信息保留

- 巅峰全屏时继续显示底部「面板与雕文」。
- 保留面板编号、名称、雕文图标和镶嵌状态。
- 页面支持纵向滚动，方便同时查看巅峰盘与面板信息。

### 操作体验

- 切换模块时采用平滑过渡，避免露出底层页面或连续闪烁。
- 完整保留技能树、巅峰盘原有的拖动、缩放、搜索和属性统计功能。

```text
https://www.d2core.com/d4/planner*
```

## 安装与使用

1. **安装脚本管理器**：先在浏览器安装 Tampermonkey（油猴）等用户脚本管理器。
2. **安装脚本**（任选其一）：
   - GitHub 一键安装：[点击安装 暗黑核-暗黑破坏神4 BD增强](https://raw.githubusercontent.com/iamvicliu/Script/main/Tampermonkey/D4-D2Core-fullscreen-enhancer/D4-D2Core-fullscreen-enhancer.user.js)
   - 国内 Gitee 镜像：[点击从 Gitee 安装](https://gitee.com/aprilfool/Script/raw/main/Tampermonkey/D4-D2Core-fullscreen-enhancer/D4-D2Core-fullscreen-enhancer.user.js)
3. **开始使用**：打开或刷新暗黑核 BD 规划器页面，点击「全屏」按钮后即可通过顶部切换栏浏览各模块或切换 BD 变体。
